# Правила работы агента в этом проекте

Проект: **Launch Control** — лабораторная работа по оптимизации Docker-упаковки
Python-сервиса. Подробности задачи: `README.md`.

## 🔴 Главный запрет: не изменять Приложение

При работе над этим проектом **ЗАПРЕЩЕНО** изменять код приложения:

- ❌ Нельзя создавать, изменять или удалять файлы в каталоге `app/`
- ❌ Нельзя создавать, изменять или удалять файлы в каталоге `tests/`

Это включает любые правки: рефакторинг, переименования, форматирование,
добавление импортов, комментариев, логов и т.п.

Чтение файлов из `app/` и `tests/` разрешено и необходимо — запрещено только
их изменение.

## Разрешённая зона работы

Задача — оптимизация упаковки, а не доработка приложения. Работать можно с:

- ✅ `Dockerfile`, `.dockerignore`
- ✅ `pyproject.toml` (зависимости), `uv.lock`
- ✅ `scripts/` (в т.ч. новый `scripts/smoke.sh`)
- ✅ `README.md`, `bench-results.md` и другие документы
- ✅ новыми вспомогательными файлами вне `app/` и `tests/`

## Исключение

Если без правки приложения задача невыполнима — остановись, явно запроси
подтверждение у пользователя и зафиксируй обоснование в `README.md`.
Без явного разрешения приложения не трогать ни при каких условиях.

## Проверка результата

После каждой задачи убеждайся, что приложение работает:

```bash
uv run pytest -q
```

Каждое улучшение подтверждается замером («было X → стало Y»), а не ощущением.
