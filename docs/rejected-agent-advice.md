## Методические заметки

1. Проверка кандидата A дала попутный честный вывод: наивный
   `uv pip uninstall && pytest` ничего не доказывает — `uv run` молча
   пересинхронизирует окружение из лока и возвращает пакет. Корректный
   эксперимент требует запуска pytest напрямую (`.venv/bin/pytest`)
   сразу после удаления.
2. Кандидаты C/D/E сознательно строились как варианты финального
   Dockerfile с одним изменением, чтобы измерить изолированный эффект.
3. Тестовые образы и файлы кандидатов после проверок удалены
   (`launch-control:cand-rootuser`, `launch-control:cand-curl`,
   distroless-образы, `Dockerfile.candidate-*`).
4. Ранее в проекте были отклонены ещё три совета с замерами
   (см. docs/agent-dialogues.md, записи 3–4): runtime на python:slim
   (dive 97.80 %), bookworm-вариант (97.92 %), точечный apt-upgrade
   util-linux (94.28 %).
